## Telas do sistema

### Produtos
![Tela de produtos](assets/produtos.png)

Tela de gerenciamento de produtos, permitindo cadastrar produtos com nome, preço, quantidade inicial e categoria, além de visualizar os produtos cadastrados.

### Movimentações
![Tela de movimentações](assets/movimentacoes.png)

Tela de controle de estoque, permitindo registrar entradas e saídas de produtos e consultar o histórico de movimentações realizadas.
